Setup and launching now live in one program, and the game installs as a portable folder.

**No game files are included.** You need your own copy of the game (US, `PCSE00011`, version 1.00) and Sony's Vita firmware.

## Install

1. Download `SilentHillBoM-PC-Setup-v0.2.0.exe` below. It holds everything setup needs, so nothing else is downloaded.
2. Run it. Windows may warn you, because the program isn't signed.
3. Choose an install folder, your firmware and your game folder, then press Install. The build takes about 8 minutes.

## What's new

- A dark, red-accented program that handles setup and launching
- A portable folder: move or copy it to another drive or PC, and it keeps working
- A `Saves` folder holding nothing but saves, ready to sync with Syncthing
- Save export and import, with a backup of whatever an import replaces
- Installing firmware from Sony's update file now works, as does a Vita3K folder
- The build runs on any PC from about 2009 onward, instead of only on processors like the one that built it

## Moving from v0.1.0

Install this version into a new folder. Then press **Import > From a folder** and choose your old `dump\decrypted\PCSE00011\recomp\fs\savedata0` folder.

## Known problems

This is an early port, tested on one Windows PC. Expect bugs and possible crashes, and keep a copy of your saves.

- Very bright surfaces can show small teal flecks
- Small dark patches may appear in some blood decals and shadows
- Text entry through the Vita's on-screen keyboard is not implemented
- Multiplayer is not implemented
- The Steam Deck and Linux build is still to come
