First public release of the unofficial Windows port of Silent Hill: Book of Memories, built with Project Nativ.

**No game files are included.** You need your own copy of the game (US, `PCSE00011`, version 1.00) and Sony's Vita firmware.

## Install

1. Download `SilentHillBoM-PC-v0.1.0.zip` below and unpack it somewhere with about 5 GB free.
2. Run `releases\Setup.bat`.
3. Choose your firmware and game folder when asked.
4. Wait for the build, which takes several minutes. Then use the new desktop shortcut.

Setup downloads the Project Nativ v0.1.5 tools (about 250 MB) from that project's GitHub release. The README has the requirements and controls.

## What works

- The game runs from the menus into gameplay, with sound and saves
- Gameplay 3D renders at full 4K
- Alt+Enter fullscreen at your display's resolution, keeping the aspect ratio
- Keyboard and mouse controls, and controllers
- Volume keys, starting at 100%, with the level remembered

## Known problems

This is an early port, tested on one Windows PC. Expect bugs and possible crashes, and keep a copy of your saves.

- Very bright surfaces can show small teal flecks
- Small dark patches may appear in some blood decals and shadows
- Text entry through the Vita's on-screen keyboard is not implemented
- Multiplayer is not implemented
- Installing firmware from Sony's update file has not been tested yet. Installing it from a Vita3K folder has.
